| `CONN-CADDY-MCP-SDK-CENTRALIZATION-R001` | **Requests use the governed SDK client.** caddy-mcp must send every vendor request through the SDK governed HTTP client with its resolved TLS profile and SDK auth. It must not build its own session. This row follows `SCION-CENTRALIZED-CAPABILITIES-R001`, `SCION-CENTRALIZED-CAPABILITIES-R003`, `SCION-CENTRALIZED-CAPABILITIES-R008`. Shape: ApiClientBase.__init__ in caddy_mcp/api/api_client_base.py builds the session with scion_sdk.http.client.create_http_client, HttpClientOptions, resolve_tls_profile("caddy") and scion_sdk.auth.static.BearerAuth or httpx.BasicAuth. | A unit test shows the API client holds an httpx client and a request carries the configured credential through a mock transport Test: `tests/test_sdk_centralization.py::test_request_goes_through_the_governed_client`. |
